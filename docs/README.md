# docs/

Design corpus for agentic-pm. Optional reading; not required to use the plugin.

## Files

- **`SKILL-PATTERN.md`** — the Socratic + compilation pattern that informs the v0.4 coach. Largely v0.3-shaped; the compilation half is superseded but the Socratic half still describes the coach's voice.
- **`WORKFLOWS.md`** — the v0.3 source of truth for skill specs. Superseded by the v0.4 playbooks (`skills/coach/reference/`); kept as design history for how the original 18 skills were structured.
- **`INTERVIEW-PROTOCOL.md`** — protocol for PM customer interviews. Referenced by the discover-ai-feature playbook conceptually.
- **`VALIDATION-PROTOCOL.md`** — protocol for validating skill quality. Still applicable to v0.4 playbook quality bars.

For the v0.4 design narrative (niche, decisions, refactor), see `PLAN.md` §0.v0.4 at the repo root.
