# Research Question Sets

Each set is a ready-to-use interview guide for one research mode. They're not generic question lists — each guide has a specific discovery goal, a screener, a structured session flow, and a "what to code for" section so synthesis is faster. The common mistake section in each guide is worth reading before you run the session, not after.

Pick the guide that matches the decision you're trying to inform. If you're not sure which one fits, use the `when_to_use` field at the top of each file.

## The 12 guides

| File | Mode | Core decision it informs |
|---|---|---|
| `jtbd-switch-story.md` | JTBD switch story | What caused someone to switch to or from your product |
| `churn-investigation.md` | Churn investigation | Why active users stopped |
| `onboarding-dropoff.md` | Onboarding drop-off | Why new users don't activate |
| `feature-adoption-gap.md` | Feature adoption gap | Why eligible users don't use a feature |
| `new-user-first-run.md` | First-run / new user discovery | What matters in the first session |
| `power-user-deepdive.md` | Power user deep-dive | What keeps your best users engaged |
| `b2b-win-loss.md` | B2B win / loss | Why deals were won or lost |
| `retention-drivers.md` | Retention drivers | What keeps mid-tier users engaged long-term |
| `opportunity-discovery.md` | Opportunity discovery | What unmet needs exist in a domain |
| `pricing-sensitivity.md` | Pricing sensitivity | Willingness to pay and value anchors |
| `ai-feature-usability.md` | AI feature usability | Where AI features fail users |
| `post-launch-impact.md` | Post-launch impact review | Whether a feature delivered its intended outcome |
