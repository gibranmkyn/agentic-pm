# Drills

A drill is a worked example of one skill running end-to-end on a concrete, realistic scenario. Each one shows the spine autoselect in action, walks through 4–5 sub-steps with real content filled in, and produces an excerpt of the actual artifact. These are not templates — they're sessions, so a PM reading one can see exactly how the skill behaves on a problem close to theirs.

Use them to preview a skill before running it, or to calibrate your own session against a reference run.
