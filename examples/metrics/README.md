# Metric Example Cards

Each card is a concrete metric tree and North Star Metric for one product archetype. Pick the card closest to your product type, read the NSM explanation and common mistake, then adapt the tree to your specific product. These are not generic — each card has a concrete NSM (not "engagement"), a realistic 3-level tree, and a common mistake that's specific to that product type.

If your product spans two archetypes (e.g., a B2B SaaS tool with a marketplace component), read both cards and note where the trees diverge — the tension points usually reveal what to measure first.

## The 10 cards

| File | Product type | NSM |
|---|---|---|
| `b2c-social.md` | B2C social / content creation | Weekly Active Creators |
| `b2c-ecommerce.md` | B2C e-commerce (DTC) | Monthly Repeat Purchase Rate |
| `b2b-saas-collab.md` | B2B SaaS collaboration tool | Weekly Active Teams |
| `b2b-saas-crm.md` | B2B SaaS CRM / sales tool | Weekly Active Reps (with ≥1 logged touchpoint) |
| `developer-tool.md` | Developer tool / API product | Weekly Active Integrations |
| `consumer-subscription.md` | Consumer subscription | Monthly Active Subscribers with ≥2 sessions |
| `fintech-payments.md` | Fintech / payments | Monthly Payment Volume per Active User |

| `ai-assistant.md` | AI assistant / LLM product | Weekly Tasks Completed |
| `healthcare.md` | Healthcare / clinical product | Monthly Active Patients with ≥1 Care Action |
